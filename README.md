# MEATZE — AI ad pipeline (10 TV spots, local ComfyUI)

Рекламные ролики для центра профессионального обучения **MEATZE** (Barakaldo + Bilbao) к ярмарке Merkalan.
10 версий по 30–70 с, 16:9, 1920×1080, 50 fps, громкость −16 LUFS (ТВ), испанский язык, два виртуальных ведущих.
Всё считается локально на одной RTX 5070 (12 GB) через ComfyUI API; картинки-первые кадры делает codex (imagegen).

> В репозитории только код, сценарии и промпты. Медиа (клипы, рендеры, голоса, фото помещений клиента,
> референсы ведущих) не публикуются.

## Стек

- **Движение:** Wan 2.2 I2V A14B GGUF Q4 (High/Low) + lightx2v 4-step — `pipeline/make_motion2.py`
  - анти-слоумо: первые 2 из 8 шагов HIGH-моделью **без** lightx2v при CFG 3 (KSamplerAdvanced ×3);
  - RIFE ×3 (16 → 48 fps) → 2xNomosUni upscale (1664×960);
  - режим first→last frame (`--last`) для переходов.
- **Липсинк:** InfiniteTalk (WanVideoWrapper, Wan2.1-I2V-480p Q4 + InfiniteTalk Single Q4) — `pipeline/make_talk2.py`
  - **обязательно** `lightx2v_I2V_14B_480p_cfg_step_distill_rank64` @ 0.7 (без неё 4 шага → «призрачное» моргание, сетка на зубах; 1.0 → широкие улыбки);
  - авто-кроп до крупного плана (`facecrop.py`, YuNet): на мелких лицах InfiniteTalk ломает глаза/зубы;
  - V2V-режим: липсинк поверх уже движущегося клипа (живые прохожие: сначала Wan-движение тела, потом губы);
  - RIFE ×2 → 50 fps.
- **Голос:** Chatterbox Multilingual (MIT), клон тембра; ASR-гейт faster-whisper (`vo_check2.py`, `cb_fixloop.sh`), обрезка тишины (`vo_trim.sh`).
- **Первые кадры:** codex CLI imagegen (`codex exec --skip-git-repo-check --approve-for-me "prompt" -i ref…` — промпт ДО `-i`). Промпты в `codex_prompts/`.
- **Монтаж:** `pipeline/cut2.py` — 50 fps, без растягивания клипов, голос отдельной дорожкой (J/L-склейки), side-chain приглушение музыки,
  loudnorm; плашки/титры (из `versions.py`), хромакей ТВ (`tvkey`), split-экран, «живые классы» (`alive`: мониторы включаются → наплыв учеников),
  кружок PiP, обрезка говорящих планов по последнему слову, проверка наложения голосов (`VOICE OVERLAP`).
- **Сборка:** `pipeline/jobs.py` (очередь GPU), `pipeline/autobuild.py` (собирает версию, когда готовы все клипы), сценарии монтажа `v1_cut.py`, `v2_cut.py`, `cuts.py`.
- **QA:** `qa.sh` (12 кадров/клип), `facegrid.py` / `faceqa.py` (лица в полном разрешении), `qa_render.sh` (лист кадров, LUFS, ASR), `facelock.py` (ReActor по эталонам, если лица «уплывают»).
- **Ремонт:** правило — брак не вырезать, а перегенерировать клип целиком (`repair.py`, `*_fix.mp4` → замена после QA).

## Выученные уроки (кратко)

1. Слоумо = растягивание клипов под озвучку + 16 fps; лечится реальным временем, RIFE и отдельной дорожкой голоса.
2. «Робот»-ведущий = застывший исходный кадр; codex-кадры с тёплым выражением + живой промпт.
3. Лица маленькие → только крупные планы для липсинка; V2V на ходу ломает лицо во втором окне 81 кадра.
4. Женские планы: InfiniteTalk добавляет улыбку с зубами → нейтральный промпт.
5. Физическая логика кадров: мониторы должны смотреть на людей (codex любит экран к камере).
6. Анимация классов с людьми «плывёт» при движении камеры → неподвижная камера, «никто не проходит сквозь мебель».
7. Немые планы с шевелением губ — запрещены (Wan «говорит» сам) → «mouth firmly closed».
8. Картинка → zoompan требует `-framerate 50`, иначе карточки вдвое короче и голоса наслаиваются.
